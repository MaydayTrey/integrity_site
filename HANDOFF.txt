=====================================================================
2. STACK AND INFRASTRUCTURE
=====================================================================
- Static site: index.html, one CSS file, one JS file, /assets
- Hosting: Netlify (Trey's account), deploy from GitHub main branch
- DNS: Cloudflare (Trey holds the domain integrityrnr.com)
- Forms: Netlify Forms (data-netlify="true"), notifications to
  phil@integrityrnr.com
- Email: Zoho Mail already live at phil@integrityrnr.com, MX/SPF/DKIM
  done in Cloudflare, Gmail forwarding verified
- Fonts: Google Fonts. Bebas Neue (display), Oswald (subheads),
  system sans or Inter (body). Self-host if CSP makes it simpler.
- Images: WebP, resized to max display width, loading="lazy" on
  everything below the fold, explicit width/height attributes on every
  <img> to prevent layout shift. Hero image is NOT lazy; use
  <link rel="preload"> for it.
- Animations: Intersection Observer for fade-ins. GSAP only if a
  specific effect needs it. Respect prefers-reduced-motion.

3. BRAND TOKENS (from the logo's vector print files, authoritative)
=====================================================================
  :root {
    --red:       #ED1C24;   /* accents, headline emphasis */
    --red-dark:  #BA1E23;   /* buttons, white text on it */
    --ink:       #231F20;   /* text; all photo overlays are this at alpha, never #000 */
    --grey-900:  #88888A;   /* dark surfaces; exact logo background grey */
    --grey-700:  #939598;
    --grey-500:  #A7A9AC;
    --grey-300:  #D1D3D4;   /* secondary text on dark */
    --grey-100:  #E6E7E8;
    --white:     #FFFFFF;
  }
Contrast rules:
  - white on --red-dark: OK everywhere
  - white on --red: headings only, never body text
  - never put body text on --grey-900
  - --red on white: headings only

Logo: export SVG from the vector PDF (Integrity__1_.pdf). Do not use
WhiteBackgroundLogo.png, it is an outdated mark with the wrong name.
Client's shirt printer is "Design 2 Wear 2" if the exact typeface is
ever needed; text in the vector files is outlined.

Slogan (exact, used as the hero headline):
  WORKING WITH YOU TO MAKE YOUR PROJECT A SUCCESS
  ("A SUCCESS" in --red)

=====================================================================
4. PAGE STRUCTURE (top to bottom)
=====================================================================
Nav (sticky): Services · Our Work · Reviews · Meet Phil · Areas Served
· Contact, plus "Get a Free Estimate" button. Collapses to a hamburger
on mobile; CTA stays visible.

1. HERO
   Full-width photo (white kitchen, from client's Facebook page,
   landscape). Dark --ink gradient overlay. Headline = slogan.
   Placeholder paragraph for a 1 to 2 sentence personal note from Phil
   with a vertical --red bar on its left (references his business
   card). Two buttons: "See Our Work" (outlined) and "Get a Free
   Estimate" (--red-dark). Trust strip under hero with icons:
   Licensed & Insured · Ohio General Contractor · Serving the Miami
   Valley. ("Insured" is unconfirmed; verify with client before launch.)
   Comp approved in principle 2026-09-05; confirm any feedback Phil gave.

2. SERVICES
   Four blocks with inline SVG icons: Kitchens, Bathrooms, Basements,
   Other. One sentence each (client supplies).

3. OUR WORK (before/after gallery)
   Filter buttons: Kitchens / Bathrooms / Basements / Other.
   2 before/after pairs per category = 16 images total.
   All 16 <img> tags in the HTML with data-category attributes; filter
   toggles a class to show/hide. Hidden items have no layout box, so
   lazy images don't fetch until revealed. Nothing injected by JS.
   Above the grid: residential intro copy (default). Small secondary
   link "Property manager or landlord?" swaps in commercial copy.
   Both copy blocks live in the HTML, hidden via CSS, for SEO.

4. REVIEWS
   Testimonial cards. Client supplies text. Structure so they can also
   be marked up with Review schema later.

5. MEET PHIL
   Portrait/family photo + two paragraphs (client supplies).

6. AREAS SERVED
   3-sentence paragraph (client supplies) + the county/city list below.
   This section carries most of the local SEO weight.

7. QUALIFICATIONS
   Badge row: Ohio General Contractor License, Water Remediation
   License, Cali Vinyl Certified Installer, Insurance-claim experience.
   Badges, not paragraphs.

8. CONTACT
   Netlify form. Fields: name, phone, email, message, service of
   interest (select: Bathroom / Kitchen / Basement / Other), urgency
   (select). Honeypot field for spam. Success redirect to /thanks.html
   (this is the Google Ads conversion endpoint required by the SOW).
   Facebook link: www.facebook.com/Integrityrnr

Footer: logo, phone, phil@integrityrnr.com, Facebook, service area
one-liner, copyright.
